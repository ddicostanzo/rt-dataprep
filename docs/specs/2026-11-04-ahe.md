# CLAHE step for every image volume (#16)

**Date:** 2026-11-04 · **Branch:** `feat/ahe-without-mclahe` · **Status:** REVIEWED (stress-test and advisor applied)
**Issue:** #16 · **Builds on:** `2026-11-03-f2b-preprocess.md` (its `## Deferred` AHE item)

## Background

Legacy preprocessing had an `ahe` step (mclahe: 3D CLAHE, kernel 1/8 of each axis, 128 bins, clip 0.05), run on the
CT after rescale and before the final spacing step. rt-dataprep shipped without it because `mclahe` pulls in
TensorFlow and pins `numpy<2` in the universal uv lock. The owner does not need to match mclahe or the existing RNT
weights' input (2026-11-04), so this is a new contrast step, not a parity port.

## Constraints

- **Clinical output:** dose and masks are never equalized. Their values and grids are unchanged with the option on or off.
  With the option off (the default), every output file, report and manifest is byte-for-byte unchanged.
- **Dependencies:** `scikit-image` is already in the lock through DicomRTTool. It becomes a direct dependency, with
  no new package in the lock.
- **PHI:** no new log line or file name source.

## Decisions (owner, 2026-11-04)

- A1 **Library:** `skimage.exposure.equalize_adapthist`. It accepts float input in [-1, 1] only, so each volume is first
  min-max scaled to [0, 1]. Parameters are fixed constants: `kernel_size` default (1/8 of each axis, at least 1),
  `nbins` 128, `clip_limit` 0.05. There are no CLI flags for them.
- A2 **Scope:** every image volume: the planning CT, each aligned plan series (CT, MR, PT) and each study series
  (CT, MR, PT). Never dose, masks or applicators.
- A3 **Position:** on each volume's own data, before it reaches the final grid, so pads and outside-FOV fill never
  enter a histogram.
  - Planning CT and study series (`process_ct`): initial resample → rescale → **ahe** → final spacing → reshape.
  - Aligned plan series (`process_series`): rescale (CT only) → **ahe** on the native grid → the one resample onto the
    final CT. Outside its FOV the value is 0, the minimum of the [0, 1] output (also for a CT series that is not
    rescaled, where today's fill is its own minimum).
- A4 **Output:** float32 in [0, 1]; skimage min-max scales its result, so a varying volume's minimum is exactly 0. The
  volume is cast to float32 before the min-max (an un-rescaled CT may be int16) and goes to skimage as float32, which
  keeps float32 out and avoids a float64 copy. The equalized image keeps the input's origin, spacing and direction
  (`CopyInformation` after the numpy round trip), so `process_series` resamples it from where the series lies. A constant volume (max == min)
  becomes all 0 by its own branch and never reaches skimage: the min-max divides by zero, and skimage returns all 1
  or a 0/1 mix for constant input depending on shape.
- A4b **No HU clip:** the min-max spans the full range for every modality. A CT with metal compresses soft tissue
  into fewer bins; that is accepted (owner).
- A5 **Naming:** the `ahe` prefix sits between `resample` and `rescale` (legacy order, newest first), on image volumes
  only: `reshape_resample_ahe_rescale_initialresample_<name>`. `output_name` today knows only `ct=` (MR/PT series and
  dose/masks both pass `ct=False`), so it gains a separate `image=` argument: `ahe_` needs `image`, `rescale_` needs
  `ct`. `STUDY_FILE` gains `(ahe_)?` and reads the series id through a named group, since a new group shifts the
  numbered one silently. It parses both study names and aligned plan-series names (`check_series_rows`).
- A6 **Switch:** a `PreprocessSteps.ahe` field (default off) and a `preprocess --ahe` flag. It works alone or with
  `--legacy-rnt`; `LEGACY_RNT` itself is unchanged. `ahe` counts as a step: an AHE-only run is accepted (not
  `REASON_NO_STEPS`, preprocess.py:260), and an MR or PT study series in it is processed (not `REASON_NO_SERIES_STEPS`,
  :376). The `geometric` check (:505) stays as is. In an AHE-only run, dose and masks are written on the native CT grid as
  in any run without geometric steps.
- A7 **Fill rule (#125):** `process_series` fills outside the FOV with 0 whenever `ahe` is on, the minimum of the
  equalized series, including a CT series that is not rescaled. The planning CT's reshape pad (its minimum) is then 0 too.
- A8 **Help text:** the CLI help that says `--legacy-rnt` is required for any output, and the `--series-fov-mask` help
  and module docstring wording that assume it, are updated to name `--ahe`.

## Approaches considered

- **NumPy port of mclahe:** exact legacy parity, about 60 lines to own. Not needed since parity is not a goal.
- **SimpleITK `AdaptiveHistogramEqualizationImageFilter`:** already a dependency, but it has no clip limit and its
  sliding window is very slow on a full CT.
- **mclahe behind a uv `conflicts` extra:** TensorFlow and `numpy<2` fork the lock, which is the problem #16 is about.

## Acceptance criteria

1. (a) AHE-only (`PreprocessSteps(ahe=True)`) on a plan with a varying CT on a non-default grid (fractional origin,
   non-unit spacing): the CT output array equals the test's own reference (float32 min-max, then
   `equalize_adapthist` called directly with the A1 constants, not the code under test); it is float32 with minimum
   exactly 0 and maximum exactly 1; its origin, spacing and direction equal the input CT's.
   (b) `LEGACY_RNT` plus `ahe`: the CT output equals the test's reference pipeline (initial resample → rescale →
   reference equalize → final spacing → reshape), float32 with values within [0, 1].
   Test volumes vary (a gradient or a landmark); a constant one becomes all 0 under A4.
2. Dose and mask outputs are identical (arrays, origin, spacing, direction, pixel ID) between `LEGACY_RNT` and
   `LEGACY_RNT` plus `ahe`.
3. An aligned MR series (on `MR_GRID`: fractional origin, non-unit spacing, translated `reg_matrix`) with `ahe` is
   equalized on its native grid and then resampled. Inside its FOV it matches `Resample(reference equalize(native))`
   with the series transform, and outside its FOV it is 0. The same holds for a non-rescaled CT series (fill 0).
4. A study MR, PT and CT series with `ahe` is equalized; an AHE-only run processes an MR study series rather than
   refusing it.
5. Output names carry `ahe_` at the A5 position for the CT, MR, PT and CT series, and none for dose or masks.
   `series_id` and the manifest read the new names for both a study series and an aligned plan series.
6. An AHE-only `preprocess` run is accepted (`--ahe` alone in the CLI); `--ahe --legacy-rnt` gives the A5 full name.
7. A constant volume becomes all 0 and is not refused.
8. With `ahe` off, all existing tests pass unchanged, except the CLI help test that pins "required for any output", which A8
   replaces.
9. `scikit-image` is a direct dependency in `pyproject.toml`; the lock gains no new package.

## Failure handling

The equalize call runs inside the existing `quiet_call(run, REASON_INTERNAL)` of `process_ct` and `process_series`,
like the other compute steps; any failure is `REASON_INTERNAL` for that case, as today. The constant-volume branch is
plain arithmetic in the same `run`.

## Delivery and validation

One PR. Tests are synthetic arrays generated at test time. Local suite, ruff, and Codex reviews the head.

## Deferred

- Peak memory: skimage works on a uint16 copy plus float64 intermediates, several times the volume's size on a large
  1 mm CT (#47 territory). Measure on the OSC run before optimizing.
- Tunable kernel, bins and clip limit (CLI flags) if a model needs other values.
- Kernel size is 1/8 of each axis in voxels: aligned plan series are equalized on their native (often anisotropic)
  grid, study series after the 1 mm resample, so the physical kernel differs. Use a fixed mm kernel if training shows
  it matters (owner).
- With `ahe` on, `rescale` no longer changes the values (min-max undoes it) yet keeps its `rescale_` prefix.
- The initial resample's 0 default at the volume edges enters the CT histogram as one more value; not measured.
- Volumes with non-finite voxels: convert already refuses those for the CT (#139). If a series ever carries NaN, the
  min-max scale turns it all NaN.
- A degenerate two-level volume (e.g. half 0, half 1) equalizes to all 1 in skimage 0.26, so its minimum is not 0 and
  the A7 fill of 0 is not its minimum. Real images are not two-level.
- A volume under about 16 voxels on an axis gets 1-voxel CLAHE tiles (kernel 1/8 of the axis) and can equalize to
  all 1 even when it varies (seen at 8^3 in tests). Real scans are far larger.
